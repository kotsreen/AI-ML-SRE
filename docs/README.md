## How to start (from scratch)

1. Open **DAILY-2-HOUR-STUDY-PLAN-FROM-SCRATCH.md** → do **Day 1** today (2 hours).
2. Create `MY-DAILY-LOG.md` using the template at the bottom of that file.
3. After Day 14, pick track A/B/C/D/E in the daily plan.
4. Use Master Guide + Workbook when the daily plan points to them.

## Suggested weekly rhythm

| Day | Activity |
|-----|----------|
| Mon–Thu | 1–1.5 hr Workbook exercises |
| Fri | System design or mock (Workbook Section 13–14) |
| Sat | Hands-on lab (profiling, GPU, or NeoLoad) |
| Sun | 10-min flash drill + STAR polish |

## Customize

Create `MY-STAR-STORIES.md` and `MY-MISSED-QUESTIONS.md` in this folder for your personal notes.
